# MotivationTimer
### MotivationTimer - это умный Wi-Fi таймер на базе esp8266 для контроля собственной производительности, а так же таймменеджмента.

![Устройство](./images/Timer-prew.jpg)
*Таймер, колхозный корпус*

### Как это работает?

У вас на столе стоит устройство с дисплеем и кнопками, если вы начинаете работать, нажимаете кнопку старт, в случае если начинаете прокрастинировать или бесполезно тратить время, просто жмете на кнопку ошибки (misstake) если вам нужно отойти или вы заканчиваете рабочую сессию, то жмете stop, при этом таймер постоянно подключен к сети wifi и отправляет ваши действия (нажатия кнопок) на бэкенд где собираеться ваша статистика, так вы можете контролировать свою производительность и видеть статистику в веб панели

## Описание проекта
Система умного таймера на базе ESP8266 с веб-интерфейсом для отслеживания статистики. Проект состоит из:
- **Бэкенд**: FastAPI сервер с PostgreSQL базой данных
- **Веб-панель**: Интерфейс с авторизацией для просмотра статистики
- **Прошивка**: Micropython код для ESP8266 (умный таймер с кнопками)
- **Корпус**: 3D модель для печати на 3D-принтере

![Схема системы](./images/schema.png)
*Схема подключения esp8266 (ВАЖНО! СХЕМА НА ПРИМЕРЕ Arduino, лишь пример, нужно подключать esp8266 по данной схеме)*

D1 = start
D2 = misstake
D3 = stop
D4 = техническая кнопка, при нажатии esp поднимает веб панель 

## Установка и запуск

### 1. Бэкенд (FastAPI + PostgreSQL)

#### Быстрый FastAPI бэкенда:
1. Запуск Postgresql и создание таблиц (читать в UseDB.py)
2. Изменить конфигурацию, создать config.py на примере exuple-config.py
3. Запуск приложения fasapi:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
fastapi run api.py
```

### 2. Прошивка для ESP8266

#### Подготовка ESP8266:

1. **Установите Micropython на ESP8266:**
```bash
esptool.py --port /dev/ttyUSB0 erase_flash
esptool.py --port /dev/ttyUSB0 --baud 460800 write_flash --flash_size=detect 0 firmware/micropython.bin
```
*Замените `/dev/ttyUSB0` на ваш порт*

2. **Загрузите файлы проекта:**
```bash
ampy --port /dev/ttyUSB0 put esp-ai-optimisation.py main.py
```

Настройка конфигурации esp:

послу запуска ждем 5 секунд и нажимаем на кнопку в D4 пине, после этого подключаемся к wifi сети ESP8266_Config
и переходим по адресу 192.168.1.1
