# MotivationTimer  

**MotivationTimer** — это умный Wi-Fi таймер на базе ESP8266 для контроля личной продуктивности и тайм-менеджмента. Он помогает отслеживать рабочие сессии, минимизировать прокрастинацию и собирать статистику вашей активности.

---

## Как это работает?

На столе находится устройство с дисплеем и кнопками:
- **Start** — начать рабочую сессию.
- **Mistake** — если отвлеклись или бездумно тратите время.
- **Stop** — завершить сессию или сделать перерыв.

Таймер постоянно подключён к Wi-Fi и отправляет данные о ваших действиях на сервер, где формируется подробная статистика. Вы можете просматривать её через веб-панель, анализировать свою эффективность и корректировать рабочий процесс.

## Структура проекта

Система состоит из трёх основных компонентов:

1. **Бэкенд** — FastAPI-сервер с PostgreSQL для хранения данных и обработки событий.
2. **Веб-панель** — интерфейс с авторизацией для просмотра статистики и графиков.
3. **Прошивка** — код на MicroPython для ESP8266 (управление таймером и кнопками).
4. **Корпус** — 3D-модель для печати на 3D-принтере.

## Установка и запуск

### 1. Бэкенд (FastAPI + PostgreSQL)

#### Быстрый старт:
1. Запустите PostgreSQL и создайте базу данных (подробнее в `UseDB.py`).
2. Настройте конфигурацию: создайте `config.py` на основе `example-config.py`.
3. Установите зависимости и запустите сервер:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
fastapi run api.py
```

---

### 2. Прошивка для ESP8266

#### Подготовка микроконтроллера:

1. **Установите MicroPython на ESP8266:**
```bash
esptool.py --port /dev/ttyUSB0 erase_flash
esptool.py --port /dev/ttyUSB0 --baud 460800 write_flash --flash_size=detect 0 firmware/micropython.bin
```
*Замените `/dev/ttyUSB0` на актуальный порт.*

2. **Загрузите файлы проекта на ESP:**
```bash
ampy --port /dev/ttyUSB0 put esp-ai-optimisation.py main.py
```

3. **Настройка Wi-Fi:**
   - После запуска подождите 5 секунд и нажмите кнопку на пине D4.
   - Подключитесь к Wi-Fi сети `ESP8266_Config`.
   - Перейдите по адресу `192.168.1.1` и заполните параметры (SSID, пароль Wi-Fi, адрес сервера и т.д.).
   - Нажмите **Save**.
